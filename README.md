# MangaMonitor

**只看你关注的作者更新了什么。隔一个月回来，点一下就能查出这段时间的新作，不用再翻完所有更新。**

这是一个 Windows 桌面程序，支持 JM 和哔咔。除了跟进作者，它还能批量下载、管理电脑上的漫画，并直接在程序里阅读。

## 核心功能：跟进关注作者的更新

**为什么需要它：** 如果你一个月甚至更久才看一次漫画，自己翻完这段时间的全部更新太花时间，里面还混着大量不想看的内容。其实你只想知道：**我关注的作者更新了什么？**

**它怎么工作：** 假设你在 10 月 1 日第一次检查，11 月 1 日再回来：

| 时间 | 你的操作 | 你看到的结果 |
| --- | --- | --- |
| 10 月 1 日 | 第一次点击“一键检查全部关注作者” | 程序读取每位作者的完整目录，列出他们到这天为止的全部作品 |
| 11 月 1 日 | 再点一次同一个按钮 | 程序优先读取上次之后新增的部分，告诉你这次新发现了多少部 |
| 随时 | 点击“仅看本次扫描新增” | 只显示这次新发现的作品，也就是从 10 月 1 日到现在新出现的内容 |

- 之前没下载的旧作品会一直保留，不会因为又检查了一次就消失。
- 页面默认只显示还没入库的作品，下载过的不用再看一遍。
- 检查只负责查找，不会自动下载，下载哪些由你决定。

**如何使用：**

1. 在“设置 → 账号与收藏”连接 JM 和哔咔，两个账号都需要。
2. 打开任意作品的详情，点击作者旁边的“关注作者”。关注的作者越全，查到的更新越完整。
3. 打开左侧的“作者更新”，点击“一键检查全部关注作者”。第一次要读取完整目录，作者多时需要等一段时间。
4. 查看结果：可以按来源筛选、按更新时间排序，或在“全部 / 已入库 / 未入库 / 状态待核对”之间切换。
5. 点击作品卡片上的“下载到漫画库”，或点击右下角的“多选”批量下载。
6. 下次想看新作时，回到这里再点一次“一键检查全部关注作者”。

**其他按钮：**

| 按钮 | 什么时候用 |
| --- | --- |
| 在“检查作者”中选一位作者 | 只想看某一位作者的更新 |
| 仅补查未完成 | 上次因为断网或读取失败没查完，只补查没完成的部分 |
| 完整复核 | 怀疑作者补录了旧作，重新读取所选范围的全部分页 |
| 刷新显示与入库状态 | 只更新显示和入库状态，不会重新扫描网站 |

> “新发现”指这部作品第一次被这个目录记录到，不一定是网站上新发布的。如果某次检查没有查完，页面会明确提示，查到 0 部也不代表作者一定没有更新。

## 自动检查更新：特别关注

**使用场景：** 有几位作者你特别想追，不想每次都手动检查。

**它怎么工作：** 每次启动程序后，它会自动在后台检查所有特别关注的作者，不影响你正常浏览。有未读新作时，侧边栏会显示数字。程序完全退出后不会继续检查。

**如何使用：**

1. 在左侧的“关注作者”中找到作者，点击“设为特别关注”，也可以在作品详情里设置。
2. 第一次检查会把作者已有的作品记为基线，之后出现的新作才算未读。
3. 打开左侧的“特别关注”查看新作，可以在“只看未读”和“全部特别关注更新”之间切换。打开某本的详情或阅读器后，这一本才标为已读；也可以点击“全部标为已读”。
4. 想马上查一次，可以点击“检查特别关注”。

## 全部功能

### 找漫画

#### 关注作者与作品

**使用场景：** 集中管理想长期跟进的作者，或先记下某一部还想继续看的作品。

**如何使用：**

- 在作品详情中点击“关注作者”或“关注作品”，也可以在同一位置取消。
- 打开左侧的“关注作者”查看名单。关注保存在本机当前账号下，不会改动网站上的关注。
- 在作者一行可以“搜索该作者”“设为特别关注”或“取消关注”。

#### 搜索

**使用场景：** 想查某位作者的全部作品，用关键词或标签找漫画，或者手上已有编号或链接。

**如何使用：**

- 打开左侧的“搜索”，选择“作者”“作品关键词”“编号或链接”或“标签”。
- 按作者搜索时会同时查询 JM 和哔咔。每位作者单独一个标签页，切换页面后结果和浏览位置都还在，重启后不保留。
- 点击封面下的作者名，或详情里的标签，也能直接搜索。

#### 在线收藏

**使用场景：** 在网站上收藏了很多作品，想看看哪些还没下载。

**如何使用：**

- 打开左侧的“在线收藏”，切换 JM 或哔咔，选择网站收藏夹；网站上有变动时点击“刷新收藏”。
- 用“已入库 / 未入库”筛选，再搜索或排序，然后批量下载没入库的作品。
- 在作品详情中点击“收藏到网站”或“取消网站收藏”。

#### 最近更新

**使用场景：** 不限于关注的作者，想随便逛逛网站最近出了什么。

**如何使用：**

- 打开左侧的“最近更新”，选择 JM、哔咔或两站合并，向下滚动继续加载，点击“刷新最近更新”读取最新内容。
- “新增”角标表示和上次浏览相比新出现的作品。

#### 周排行榜

**使用场景：** 想知道最近大家都在看什么，发现还不认识的作者。

**如何使用：**

- 打开左侧的“周排行榜”，查看 JM 每周必看或哔咔排行榜，JM 可以选择期数和类型，点击“刷新榜单”重新读取。
- 用“未入库”筛掉已经有的作品，再下载想看的。

#### 作品详情

**使用场景：** 下载前先确认页数、章节、更新时间、作者和标签。

**如何使用：**

- 点击作品标题，或右键封面选择“作品详细”。
- 可以在详情里下载、收藏到网站、关注作者或作品，也可以点击标签继续搜索。

#### 内容过滤与标记

**使用场景：** 不想看到某些类型的作品，也想一眼分清是否已汉化。

**如何使用：** 这些都是自动的，不需要设置。

- 明确标有 BL／耽美或 AI 作画的作品，以及 JM 的“女性向”作品，会自动隐藏。网站没有标注的内容无法识别。
- 封面上显示“已汉化”“生肉”或“未知”，只依据网站标签，不靠标题猜测。“生肉”表示未翻译，不一定是日文。

### 下载与管理

#### 下载队列

**使用场景：** 一次下载很多本，中途可能要暂停，或者下载失败后要重试。

**如何使用：**

- 在任意列表点击“下载到漫画库”，或点击“多选”后勾选批量下载。
- 也可以打开左侧的“下载队列”，选择来源后粘贴编号或链接（每行一个，一次最多 500 本），再点击“加入下载”。
- 在“下载中”“下载失败 / 需要处理”“已下载”三个分类之间查看，可以暂停、继续、重试或放弃任务。
- 每本保存为一个 ZIP，保存、验证、登记都完成才算成功。已有文件不会被覆盖，同名冲突时会提示。

在“设置 → 下载与资源”可以调整同时下载的作品数和全局图片请求数。

#### 电脑漫画库

**使用场景：** 电脑里已经有不少 ZIP 漫画，想用封面墙浏览和查找。

**如何使用：**

- 在“设置 → 漫画库”选择文件夹，已有漫画不用搬迁。
- 打开左侧的“漫画库”，可以搜索、筛选、按时间排序，并调整封面密度。
- 手动移动或删除文件后，点击“刷新漫画库”重新核对。
- 右键封面可以“打开文件位置”或“删除漫画”。删除前会确认，文件只会移到 Windows 回收站。

### 阅读

#### 内置阅读器

**使用场景：** 不想再装其他阅读软件，下载完直接看；或者一边看漫画一边做别的事。

**如何使用：**

- 右键封面，选择“程序内阅读”或“小窗阅读”；双击封面也能打开小窗。
- 支持纵向滚动和单页翻页。单页模式下点击左半边或右半边翻页，也可以用键盘左右键。
- Ctrl＋滚轮缩放，F11 全屏；鼠标移到底部显示工具栏，可以拖动进度条或选择章节。
- 可以同时打开多个小窗并按需置顶，阅读位置会自动保存。

#### 浏览历史

**使用场景：** 想找回前几天看过、但当时没收藏的作品。

**如何使用：**

- 打开左侧的“浏览历史”，这里带封面显示最近打开的 100 本。
- 只有打开详情或阅读器才会记录。可以取消勾选“记录浏览历史”，也可以点击“清空历史”；两者都不影响漫画文件和阅读进度。

### 设置

#### 账号登录

**使用场景：** 查询和下载都需要来源账号，又不想每次打开都重新登录。

**如何使用：** 在“设置 → 账号与收藏”分别登录 JM 和哔咔。可以选择“记住会话”；JM 还可以选择“记住登录”。

#### 外观

**使用场景：** 想把界面换成自己喜欢的样子。

**如何使用：** 在“设置 → 外观”选择背景预设或自定义背景图，调整背景模式、暗化、模糊和封面密度，也可以减少动态效果。

#### 诊断

**使用场景：** 遇到问题，想反馈但不想泄露隐私。

**如何使用：** 在“设置 → 网络与诊断”查看版本和提交号，复制状态摘要后提交到 [Issues](https://github.com/gouluanjiang/MangaMonitor-AI/issues)。摘要不含账号、作品标题和私人路径。

## 快速开始

1. 从[发行页](https://github.com/gouluanjiang/MangaMonitor-AI/releases/latest)下载 `MangaMonitor.Dev_<版本>_x64-setup.exe`，可用同页的 `SHA256SUMS.txt` 核对文件。
2. 关闭正在运行的 MangaMonitor 和阅读小窗，然后运行安装包。
3. 打开“设置 → 漫画库”，选择你的漫画文件夹。
4. 打开“设置 → 账号与收藏”，连接 JM 和哔咔（JM 请先看上方提示）。
5. 关注几位作者，然后到“作者更新”点击“一键检查全部关注作者”。

**运行环境：** Windows x64，需要 Microsoft Edge WebView2。缺少时安装程序可能会联网下载。

## 使用前请了解

- **需要你自己的账号：** 程序不附带账号、书目或漫画。
- **内容来自第三方网站：** 这些网站可能包含成人内容，也可能随时不可用。请遵守当地法律和网站条款。
- **安装包没有代码签名：** Windows 可能弹出安全提示，请只从本仓库发行页下载。
- **目前没有内置更新器：** 程序不会检查自身的新版本，新版本需要手动下载安装。
- **名称里的 Dev：** 安装后显示为 MangaMonitor Dev，只是为了沿用原有的安装记录和数据，不代表测试版。
- **自动检查的范围：** 只有特别关注会在启动时自动检查；普通关注要手动点击。程序不会定时扫描，退出后也不会检查，任何检查都不会自动下载。
- **不靠猜测判断同一本：** 程序不按相似标题判断，也不自动合并两个网站的同一部作品。所以有文件但没有来源记录的旧漫画，可能显示为“未入库”或“待核对”。

## 隐私与数据

- 账号、关注名单和漫画库只保存在你的电脑上，不会上传到 GitHub。
- 记住会话和 JM 的“记住登录”都是可选功能，凭据保存在 Windows 系统安全存储中，不写入普通设置文件。
- 反馈问题时请不要附上账号或密码。

## 常见问题

**显示“未入库”，但我电脑上有这本？**
入库状态只依据同来源的下载记录、已核对的旧库登记和实际文件，不靠标题猜测。详见[使用指南](docs/USER_GUIDE.md#已入库的含义)。

**怎么完全退出或更新？**
关闭主窗口后，如果还有阅读小窗，程序可能仍在运行。安装新版前请关闭所有窗口，也不要同时运行不同版本。

**能在浏览器或 Mac 上用吗？**
不能。真实账号、漫画库和下载只有 Windows 桌面端提供；开发用的浏览器预览只显示合成数据。
