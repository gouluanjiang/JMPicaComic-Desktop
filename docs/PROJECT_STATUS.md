# JMPicaComic-Desktop 项目状态

更新日期：2026-11-11。**当前正式版为 [1.2.0](https://github.com/gouluanjiang/JMPicaComic-Desktop/releases/tag/v1.2.0)**。变化见[版本说明](RELEASE_NOTES_1.2.0.md)。

## 1.2.0 新增

软件内更新（启动时检查、确认后安装、签名校验）；开发中的 ASMR 分区：浏览 asmr.one 的作品，在线播放音频和视频，字幕和桌面字幕。漫画部分没有变化。

## 1.1.0 新增

新界面和更大的文字；JM 域名更新、发送凭据前的域名验证和有界切换；每周必看空类型名修复；按文件时间修正入库时间；按文件内容核对下载记录；批量移除异常历史记录；线路诊断。

| JM／哔咔浏览 | 在线收藏、作者／关键词／标签搜索、单站及组合最近更新、榜单、连续分页、详情与直接下载 |

| 入库状态 | 同来源下载记录、已核对登记与实际文件共同判断；不通过标题相似度猜测，不自动跨站认定同本 |
| 作者更新 | 普通关注手动增量、完整复核、补查未完成；旧遗漏保留，异常逐项说明；目录与详情证据合并，保留已确认作者归属 |
| 特别关注 | 首次作品基线、冷启动受限检查、未读作品计数；进入栏目不全部已读，打开详情／阅读才标记该条；独立于扫描新增 |
| 新增标记 | 最近更新与作者更新按每次启动固定浏览基准；扫描新增按稳定身份差异记录，部分失败不冒充完整成功 |
| 下载 | 单本／批量直接提交，不二次确认或强制跳页；暂停、重试、异常提示及失败任务处理；一本一个 ZIP，验证和登记后才成功 |
| 阅读与历史 | 内置阅读及多个独立小窗、两种模式、缩放、全屏、进度恢复与置顶；最近 100 本历史含封面、清空和关闭记录 |
| 封面与内容 | 可见项优先、请求复用、有界重试；沿用网站语言标签；只按明确已有标签过滤 BL／AI／JM 女性向，未知直接显示，无额外逐本过滤请求 |
| 账号与诊断 | 两源会话恢复、JM 可选系统凭据库记住登录；版本／源码号及不含私人资料的错误摘要 |
| 软件更新 | 启动时或手动检查 GitHub 发行页；用户确认具体版本后才下载，校验签名且签名文件名须带该版本号；下载队列运行时拒绝安装 |
| ASMR 分区（开发中） | asmr.one 作品的浏览、排序、搜索和详情；音频／视频在线播放，不写入磁盘；VTT／LRC／SRT 字幕、桌面字幕小窗、可拖动的视频小窗；不使用账号 |

## 1.0.2 验证边界（历史）

1.0.2 重新由 CI 构建；版本说明更新不替代准确源码的基础、前端和 Windows 原生／安装检查。CI、Windows 专项和用户体验是不同证据。

本地 37 项专项收尾为 **28 通过、0 失败、0 受阻、8 项用户决定不再测试、1 项留待用户自然体验**。各项保留自己的提交与测试层次，不称为 37 项在最终包上全部原生通过，也不重启已取消项目。

LOCAL-01 最近更新元数据回写、LOCAL-02 占用文件拒绝回收后的库存状态均已修复并定向复测。测试合成文件已经移出漫画库，测试登记已清理；正式发行不附带测试漫画或私人资料。

## 已知边界与后续

- **LOCAL-03**：CI 冷启动最近更新页曾有 15 像素滚动偏差，同源码重跑通过，根因未定；仍保留问题记录，没有宣称修复。
- 本机 NSIS 安装尝试遇到临时目录错误，最终通过已核验发行载荷原位更新；应用文件、原桌面入口和资料保留已确认。窗口工具未恢复，本轮更新后的原生画面检查未完成，详见发行记录。
- 特别关注的真实自然更新提醒由用户日后实际体验；模拟测试不替代该验收。取消的长时间 Windows 性能等测试不补写通过结论。
- 网站缺失元数据、限流、登录失效和未完成分页仍会影响可查询范围。JM 不包含网页端 English Manga 分类；“完整”指本次支持范围的完整读取，不保证网站提供全部出版物。
- Windows 包未代码签名；缺少 WebView2 时可能联网安装。旧程序不能安全打开格式版本 2 资料，升级前备份，不无条件降级。
- 软件内更新在 1.2.0 首次提供；下载、验签和安装的完整流程要等下一个版本发布后才第一次实际运行。
- ASMR 分区不支持 ASS 字幕，内核无法解码的格式只提示、不转码；asmr.one 的接口和媒体地址编译在程序里。
- 后续方向见 README 的“未来计划”：ASMR 的视频小窗改进、关注、账号同步、下载和本地库，都还没有开始开发。视频来源不再计划加入。

应用标识、私有目录和凭据命名空间沿用既有值，安装名称保留 MangaMonitor Dev。云端自动监控保持关闭，`production_enabled=false` 不变。自动猜测匹配、跨站版本推断与替换、不喜欢标记、托盘／自启等此前取消的范围不因历史计划重新进入待办。

接手开发先读 [当前交接](DEVELOPMENT_HANDOFF.md)和 [文档导航](README.md)，核对当前 main 和工作区状态。历史工作树、候选包、个人核对清单不作为当前正式版本身份；私有安装与资料证据保留在仓库外。
