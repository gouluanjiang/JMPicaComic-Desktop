# JMPicaComic-Desktop 1.1.0

本项目原名 MangaMonitor。这一版修复了 JM 无法使用的问题，并重新设计了界面。

## 请先看：JM 账号安全

1.0.2 内置的 JM 主域名后来失效，变成了停放页。在 1.0.2 上登录 JM 时，账号密码可能已经发送到这个域名。

如果你在 2026 年 10 月中旬之后用 1.0.2 登录过 JM，建议修改 JM 密码；其他网站用了相同密码的，也一并修改。1.1.0 在发送账号密码之前，会先验证域名确实是 JM 的服务。

## 修复

- **JM 恢复可用：** 更新了固定域名列表，一个域名失效时会切换到下一个。登录、收藏、搜索和详情都恢复正常。
- **JM 每周必看恢复可用：** JM 返回了没有名称的榜单类型，导致整个榜单加载失败。
- **入库时间恢复准确：** 取下载入库时间和文件修改时间中较早的一个。重新读取目录不会再让所有作品都变成同一天入库，“最近入库”也会显示真正最新的作品。
- **卡片不再显示文件名：** 没有作者资料的作品会显示“作者资料未取得”，不再把 ZIP 文件名放在标题下面。

## 新功能

- **全新界面：** 窄图标侧栏，封面优先，自定义背景作为顶部横幅。漫画库新增“最近入库”。
- **更大的文字：** 正文和按钮放大到 14px，次要信息至少 13px，灰色文字也更亮。
- **按文件内容核对：** 漫画文件夹被迁移、恢复或重新选择后，已下载记录可能显示“目录不可用”，即使文件还在。现在可以在“下载失败 / 需要处理”点击“按文件内容核对”恢复这些记录。这一步只读取漫画文件，不会改动它们。
- **批量移除历史记录：** 文件确实不在了的已下载记录，可以一次移除，文件不受影响。
- **线路诊断：** “设置 → 网络与诊断”可以查看当前线路和异常的 JM 域名。

## 其他变化

- 封面上不再显示“未知”语言标记，详情页仍然保留。
- 网络故障时更快结束等待：连接超时 10 秒，切换域名最多 45 秒，整站故障时短暂快速失败。
- 软件内的名称改为 JMPicaComic-Desktop。

## 升级

退出主窗口和所有阅读小窗后运行安装包，**不需要卸载旧版**，漫画库、关注、下载记录和设置都会保留。

安装名称仍是 MangaMonitor Dev，应用标识和数据目录也没有变，这是为了沿用现有数据。升级前建议备份，不要再用旧版程序打开新版写入的数据。

## 已知事项

- 安装包没有代码签名，Windows 可能弹出安全提示，请只从本仓库发行页下载。
- 程序还没有内置更新器，新版本需要手动下载。
- JM 图片域名仍然只有一个，它失效时阅读和下载会失败，需要等新版本更新。
- 域名列表编译在程序里，JM 更换全部域名时也需要新版本。
- 云端自动监控没有启用。

验证范围、文件哈希和其他发行信息见本版本的发行页。
