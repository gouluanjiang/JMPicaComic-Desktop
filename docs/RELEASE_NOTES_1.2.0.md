# JMPicaComic-Desktop 1.2.0

这一版加入了软件内更新和 ASMR 分区。漫画部分的功能和数据格式没有变化。

## 新功能

### 软件内更新

- 程序启动时会检查 GitHub 上有没有新版本，有就在右上角提示。
- 点击“查看更新”可以看到版本说明，确认后才会下载和安装。
- 安装包会先校验签名。校验通过后，程序和所有阅读小窗会关闭，安装完成后自动重新打开。
- 下载队列运行时不能安装，请先暂停或等下载完成。
- 不想在启动时检查，可以在“设置 → 网络与诊断 → 软件更新”关闭，也可以在那里手动检查。

**1.2.0 本身仍需手动安装。** 1.1.0 和更早的版本没有更新功能，请到发行页下载安装包。装上 1.2.0 之后，以后的新版本就可以在软件内更新。

### ASMR 分区（开发中）

侧栏顶部新增“漫画 / ASMR”切换。ASMR 分区的内容来自 asmr.one，浏览和播放都不需要账号。

- **浏览：** 热门作品和全部作品，可以按最新收录、发售日期、下载量、评分或评论数排序，也可以只看带字幕的作品。列表向下滚动会继续加载。
- **查找：** 搜索标题、社团、声优或 RJ 号，也可以按社团、声优、标签查看作品，或者用“随机听”。
- **显示：** 封面网格和详细卡片两种方式，浅色和暗色两种主题。
- **作品详情：** 点开作品会在右侧显示详情和文件列表，不离开当前列表。
- **在线播放：** 音频和视频直接播放，不会保存到电脑上。底部是播放条，展开后是完整播放器，里面有字幕列表（点一句跳到那里）和播放列表。
- **字幕：** 支持 VTT、LRC 和 SRT。播放带字幕的文件时，字幕还会显示在一个置顶的透明小窗里，可以拖到桌面任意位置并调整字号，位置和字号会记住。
- **视频：** 收起播放器时，视频缩成一个可以在 ASMR 页面里拖动的小窗；展开后可以全屏。
- **版本文件夹：** 作品有多个版本时，优先选中文、带字幕、无损原档的版本；只差“有无音效”时会问一次并记住选择。
- **播放控制：** 快捷键和键盘媒体键、播放速度、睡眠定时，每个文件记住听到的位置。切到漫画分区时会继续播放。

切回漫画分区时，原来的页面和浏览位置都会保留。

这个分区还在开发中：关注、账号同步、下载和本地库都还没有。

## 升级

退出主窗口和所有阅读小窗后运行安装包，**不需要卸载旧版**，漫画库、关注、下载记录和设置都会保留。

安装名称仍是 MangaMonitor Dev，应用标识和数据目录也没有变，这是为了沿用现有数据。升级前建议备份。

## 已知事项

- 软件内更新在这一版首次提供。下载、校验签名和安装的完整流程，要等下一个版本发布后才会第一次实际运行；更新失败时仍可到发行页手动下载安装包。
- 安装包没有 Windows 代码签名，手动安装时 Windows 可能弹出安全提示，请只从本仓库发行页下载。
- asmr.one 是第三方网站，可能随时不可用。它的接口和媒体地址编译在程序里，网站更换地址时需要等新版本。
- ASMR 暂不支持 ASS 字幕。内核无法解码的音频或视频格式会提示无法在线播放，程序不会转码。
- ASMR 的播放位置、主题和窗口位置只保存在本机，不会同步到 asmr.one 账号。
- JM 图片域名仍然只有一个，它失效时阅读和下载会失败，需要等新版本更新。
- 云端自动监控没有启用。

验证范围、文件哈希和其他发行信息见本版本的发行页。
