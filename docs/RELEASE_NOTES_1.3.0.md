# JMPicaComic-Desktop 1.3.0

这一版改进了 ASMR 分区：视频小窗可以调整大小、弹到程序之外，还可以登录 asmr.one 账号，管理收藏、标记和播放列表。漫画部分的功能和数据格式没有变化。

## 新功能

### 视频小窗

- **调整大小：** 拖动小窗的四个角可以放大缩小，画面比例保持不变，大小会记住。
- **画中画：** 点小窗上的“画中画”按钮，视频会变成一个置顶的系统小窗，可以拖到程序窗口之外，切到漫画分区或其他程序时继续看。把小窗拖出程序窗口再松手也会弹出。
- 画面里自带的字幕照常显示；单独的字幕文件仍由桌面字幕小窗显示。

### asmr.one 账号

ASMR 页面右上角新增“登录”。浏览和播放仍然不需要账号，登录后可以使用下面这些功能。

- **登录保持：** 密码只发给 asmr.one，程序不保存。登录后网站发的令牌保存在 Windows 凭据管理器里，有效期约一年，重启程序不用重新登录。令牌失效时程序会提示重新登录。
- **我的收藏：** 侧栏新增“我的收藏”，按想听、在听、听过、重听、搁置显示你标记过的作品，可以按标记时间正序或倒序排列。
- **标记和评分：** 作品卡片上显示你的标记；作品详情里可以直接改标记、打一到五星，“清除”会同时去掉标记和评分。
- **播放列表：** 侧栏新增“播放列表”，和网站上的是同一份。作品详情里的“加入播放列表”可以把作品加入或移出列表；“播放列表”页可以新建列表，也可以编辑或删除自己建的列表（删除前会再确认一次）。网站自带的“我标记的”等列表不能改名或删除。
- **自动标记：** 默认开启。开始播放时，还没标记或是“想听”的作品会标为“在听”；播完最后一个文件时会标为“听过”。“听过”“重听”“搁置”不会被改动。点右上角的用户名可以关闭。

这些修改都直接保存到你的 asmr.one 账号，网站上会同步看到。

## 升级

**1.2.0 可以直接在软件内更新：** 启动后右上角会提示新版本，点“查看更新”确认即可。也可以到发行页下载安装包手动安装。

手动安装时，退出主窗口和所有阅读小窗后运行安装包，**不需要卸载旧版**，漫画库、关注、下载记录和设置都会保留。1.1.0 和更早的版本没有更新功能，需要手动安装。

安装名称仍是 MangaMonitor Dev，应用标识和数据目录也没有变。升级前建议备份。

## 已知事项

- 这是第一次在两个正式版本之间使用软件内更新。更新失败时，仍可到发行页手动下载安装包。
- asmr.one 账号的修改功能按网站自身的接口实现，网站改动接口后可能暂时无法使用，需要等新版本。
- ASMR 的下载和本地库还没有。
- ASMR 暂不支持 ASS 字幕。内核无法解码的音频或视频格式会提示无法在线播放，程序不会转码。
- 安装包没有 Windows 代码签名，手动安装时 Windows 可能弹出安全提示，请只从本仓库发行页下载。
- JM 图片域名仍然只有一个，它失效时阅读和下载会失败，需要等新版本更新。
- 云端自动监控没有启用。
