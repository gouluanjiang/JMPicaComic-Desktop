# JMPicaComic-Desktop 1.4.0

这一版重做了界面：换成藏青＋金色的配色，页面说明收进标题旁的 i 按钮，主窗口和阅读小窗都去掉了 Windows 标题栏。功能和数据格式没有变化。

## 新界面

- **藏青＋金色：** 整个程序换成藏青底色和金色强调，按钮、下拉框和搜索框统一成圆角样式，主要操作是金色按钮。“已汉化”“生肉”“新增”等角标也统一成同一种样式。
- **ASMR 分区跟随同一套配色：** ASMR 不再有单独的白底主题和亮暗切换，侧栏和漫画分区一致。
- **页面说明收起来了：** 每个页面标题旁有一个 i 按钮，副标题、统计说明和帮助文字点开才显示，主界面更简洁。错误提示、状态提示和空页面的说明仍然直接显示。

## 去掉了 Windows 标题栏

- **主窗口：** 最小化、最大化和关闭按钮放在右上角，叠在顶栏最右边。按住顶栏空白处可以拖动窗口，双击可以最大化或还原；拖到屏幕边缘自动贴边、拖窗口边缘改大小都和以前一样。
- **阅读小窗：** 漫画铺满整个小窗。鼠标移到小窗最顶端，会滑出一条标题栏，可以拖动，也有最小化、最大化和关闭按钮；点关闭会先保存阅读位置。
- 全屏时这些按钮会隐藏。

## 升级

**1.2.0 和 1.3.0 可以直接在软件内更新：** 启动后右上角会提示新版本，点“查看更新”确认即可。也可以到发行页下载安装包手动安装。

手动安装时，退出主窗口和所有阅读小窗后运行安装包，**不需要卸载旧版**，漫画库、关注、下载记录和设置都会保留。1.1.0 和更早的版本没有更新功能，需要手动安装。

安装名称仍是 MangaMonitor Dev，应用标识和数据目录也没有变。升级前建议备份。

## 已知事项

- 自己画的最大化按钮没有 Windows 11 鼠标悬停时弹出的窗口布局菜单。
- 程序内阅读时漫画铺满窗口，没有空白处可以拖动窗口，要移动窗口请先退出阅读。
- 项目主页上的截图是 1.3.0 的界面，和新配色不同。
- ASMR 的下载和本地库还没有；暂不支持 ASS 字幕。
- 安装包没有 Windows 代码签名，手动安装时 Windows 可能弹出安全提示，请只从本仓库发行页下载。
- JM 图片域名仍然只有一个，它失效时阅读和下载会失败，需要等新版本更新。
- 云端自动监控没有启用。
