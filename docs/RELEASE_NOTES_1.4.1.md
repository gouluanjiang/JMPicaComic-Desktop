# JMPicaComic-Desktop 1.4.1

这一版主要解决 1.4.0 用久了会变卡的问题，顺带修了几处界面细节。功能和数据格式没有变化。

## 更流畅

- **切换页面不再卡顿：** 去过的页面会留在后台，以前主窗口每有一点变化，它们都要跟着重新计算一遍，“最近更新”的列表越长越明显。现在后台页面只在自己的数据变化时才更新，切换页面、翻页、搜索输入基本没有可感觉到的停顿。
- **开着阅读小窗时更顺：** 以前从阅读小窗回到主窗口，第一次翻页或关闭漫画会卡一下，现在不会了。
- **“最近更新”和作者页更快：** “最近更新”不再每次打开都把整个作者目录重新读一遍、重新计算，只在目录真的变化时才更新；关注作者很多时，作者页的列表也只在关注名单变化时重画。
- **少做没必要的读取：** 切换页面时不再重复读取已下载作品清单；下载完成、漫画库变化、回到窗口或手动刷新时照常更新。

在关注作者较多、最近更新列表较长的电脑上实测，切换页面时最长的一次停顿从 250–800 毫秒降到大多不到 50 毫秒；程序启动后第一次打开“最近更新”仍需完整读取一次作者目录，会有一次短暂停顿。

## 界面修正

- **下拉框文字居中：** 下拉框里的文字和箭头在框内上下居中。
- **期数更好读：** JM 每周必看的期数显示为“2026 年第 265 期 · 11.06–11.13”这样的格式，跨年的期数也按正确顺序显示。
- **小窗标题栏更容易呼出：** 阅读小窗里，鼠标靠近顶部一定范围内就会滑出标题栏，不用再对准最顶端那一条线；鼠标移开一段距离或离开窗口后自动收起。

## 升级

**1.2.0 及以后的版本可以直接在软件内更新：** 启动后右上角会提示新版本，点“查看更新”确认即可。也可以到发行页下载安装包手动安装。

手动安装时，退出主窗口和所有阅读小窗后运行安装包，**不需要卸载旧版**，漫画库、关注、下载记录和设置都会保留。1.1.0 和更早的版本没有更新功能，需要手动安装。

安装名称仍是 MangaMonitor Dev，应用标识和数据目录也没有变。升级前建议备份。

## 已知事项

- 程序启动时会联网核对 JM 和哔咔的登录，网络慢时设置里会显示“正在恢复”一两分钟，核对完成后自动变为已连接。
- 自己画的最大化按钮没有 Windows 11 鼠标悬停时弹出的窗口布局菜单。
- 程序内阅读时漫画铺满窗口，没有空白处可以拖动窗口，要移动窗口请先退出阅读。
- ASMR 的下载和本地库还没有；暂不支持 ASS 字幕。
- 安装包没有 Windows 代码签名，手动安装时 Windows 可能弹出安全提示，请只从本仓库发行页下载。
- JM 图片域名仍然只有一个，它失效时阅读和下载会失败，需要等新版本更新。
- 云端自动监控没有启用。
